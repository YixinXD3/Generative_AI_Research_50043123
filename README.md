# Generative AI Research Project

This repository was created for REIT6811 Applied Class 6: Comprehensive Data Handling in Research.

The project is based on the research topic:

**Using Generative AI Tools – Boon or Bane**

The purpose of this repository is to organise research materials clearly, apply version control using Git and GitHub, and support collaborative research work.

## Repository Structure

The repository is organised into the following main folders:

- `01_Literature`  
  Contains literature review materials, including journal articles, conference papers, books, and other relevant sources.

- `02_Quantitative`  
  Contains quantitative research materials such as survey questions, raw and processed survey data, Python scripts, Excel/CSV files, and analysis results.

- `03_Qualitative`  
  Contains qualitative research materials such as interview protocols, interview transcripts, analysis notes, and data visualisations.

- `04_Drafts`  
  Contains draft research proposals, conference papers, and other working documents.

- `05_Final_Report`  
  Contains final research reports and completed research outputs.

- `06_Media`  
  Contains supporting materials such as images, photos, and other media files.

## File Naming and Organisation

Files should use clear and descriptive names so that team members can easily identify their purpose and content.

Where appropriate, filenames should indicate the type, status, or version of the file.

For example:

`survey_raw.csv`

`survey_cleaned.csv`

`survey_analysis.py`

Clear naming conventions help reduce confusion, avoid duplication, and make project files easier to manage.

## Version Control

Git and GitHub are used to track changes made throughout the research project.

Contributors should use meaningful commit messages that clearly describe their changes.

Examples include:

`Add initial survey data`

`Update qualitative analysis notes`

`Add cleaned dataset and analysis script`

## Contribution Guidelines

Future collaborators should follow these steps when contributing to the repository:

1. Create a new branch before making significant changes.
2. Make changes to the appropriate files or folders.
3. Review the changes before committing.
4. Use a clear and meaningful commit message.
5. Push the branch to GitHub.
6. Create a pull request.
7. Review and resolve any merge conflicts if necessary.
8. Merge approved changes into the `main` branch.

## Data Management

Research data should be stored and managed carefully.

Sensitive or confidential research materials, such as participant consent forms, identifiable survey responses, or interview data containing personal information, should not be made publicly accessible.

Access to sensitive data should be restricted to authorised research team members.

## Purpose

This repository demonstrates how structured file organisation, clear naming conventions, version control, and collaborative workflows can support effective research data management.
